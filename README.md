Side Quest Week 2

Setup and Interaction Instructions
Right-click on `index.html` and open in broswer using Live Server.

Goal: Get to the top platform!
To move left/right: Arrow Keys or A/D
To jump: Up Arrow or W
To restart: fall off any platform
